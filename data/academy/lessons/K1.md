## Where we are

Nothing exists yet. You have the Java fundamentals from JAVA-FUND-2 to JAVA-FUND-5: classes and interfaces, `equals`/`hashCode`, immutability, exceptions and generics. Today you start TicketHub in **your own new repo**, as a plain Maven project with no Spring and no database. You get the domain right first, while it is cheap to change.

## Goal

Model the TicketHub domain (venues, seats, events, seat holds and bookings) as small, immutable Java 21 types. Each type rejects invalid state in its constructor, so a bad object can never exist. You also define the error types the API will later turn into HTTP responses, and you take time from an injected `Clock`, so tests can freeze it. Everything is covered by fast JUnit 5 + AssertJ tests. Every later milestone builds on these exact names, so keep them as written here.

## What you build

- [ ] A Maven project `tickethub` (Java 21, JUnit 5, AssertJ), package `com.tickethub`
- [ ] `event` package: `Venue`, `Seat`, `Event` records, plus the `PriceCategory` enum
- [ ] `booking` package: `SeatHold` record, `Booking` class (identity equality), `BookingStatus` enum with its allowed transitions
- [ ] `common` package: `TicketHubException` (unchecked, stable `code()`)
- [ ] `SeatUnavailableException`, `HoldExpiredException`, `BookingNotFoundException` in `booking`
- [ ] Money as `long` cents, time as `Instant`, "now" always read from a `Clock` parameter
- [ ] Unit tests for every invariant and for the equality rules

### 2. Value types as records (15 min)

A **value type** is an object defined entirely by its fields: two `Seat`s with the same id, venue, row and number are the same seat. Records give you `equals`, `hashCode` and `toString` from all fields, which is exactly value semantics (JAVA-FUND-3). A **compact constructor** is the record's place to check invariants. An **invariant** is a rule that must always be true for the object.

```java
package com.tickethub.event;

public record Seat(long id, long venueId, int row, int number) {
    public Seat {
        if (id <= 0 || venueId <= 0) throw new IllegalArgumentException("ids must be positive");
        if (row < 1 || number < 1) throw new IllegalArgumentException("row and number start at 1");
    }
}
```

`Venue` also knows how to produce its seats. The seat ids are deterministic so that tests and the JSON seed (CAPSTONE-2) stay stable. CAPSTONE-5 replaces them with database ids.

```java
package com.tickethub.event;

import java.util.ArrayList;
import java.util.List;

public record Venue(long id, String name, int rows, int seatsPerRow) {
    static final int MAX_SEATS = 999;   // keeps id = venueId * 1000 + position unique

    public Venue {
        if (id <= 0) throw new IllegalArgumentException("id must be positive");
        if (name == null || name.isBlank()) throw new IllegalArgumentException("name is required");
        if (rows < 1 || seatsPerRow < 1) throw new IllegalArgumentException("rows and seatsPerRow must be >= 1");
        if (rows * seatsPerRow > MAX_SEATS) throw new IllegalArgumentException("at most " + MAX_SEATS + " seats");
    }

    public List<Seat> seats() {
        List<Seat> seats = new ArrayList<>(rows * seatsPerRow);
        for (int r = 1; r <= rows; r++) {
            for (int n = 1; n <= seatsPerRow; n++) {
                long seatId = id * 1_000 + (long) (r - 1) * seatsPerRow + n;
                seats.add(new Seat(seatId, id, r, n));
            }
        }
        return List.copyOf(seats);
    }
}
```

`PriceCategory` is the event's price tier: it sets the base price of one seat, in cents. CAPSTONE-7 keeps it as the base and
adds a separate `PricingRule` (standard, early-bird, surge) on top, each rule a strategy.

### 3. The hold, with a Clock (10 min)

A `Clock` is the JDK's abstraction for "what time is it". Production passes `Clock.systemUTC()`; tests pass `Clock.fixed(...)`. Then a test about expiry never has to sleep.

```java
package com.tickethub.booking;

import java.time.Clock;
import java.time.Duration;
import java.time.Instant;
import java.util.HashSet;
import java.util.List;
import java.util.UUID;

public record SeatHold(UUID id, long eventId, String userId, List<Long> seatIds, Instant expiresAt) {
    public SeatHold {
        if (id == null || expiresAt == null) throw new IllegalArgumentException("id and expiresAt are required");
        if (userId == null || userId.isBlank()) throw new IllegalArgumentException("userId is required");
        if (seatIds == null || seatIds.isEmpty()) throw new IllegalArgumentException("hold at least one seat");
        seatIds = List.copyOf(seatIds);   // immutable copy; also rejects null elements
        if (new HashSet<>(seatIds).size() != seatIds.size()) throw new IllegalArgumentException("duplicate seat ids");
    }

    public static SeatHold create(long eventId, String userId, List<Long> seatIds, Clock clock, Duration ttl) {
        return new SeatHold(UUID.randomUUID(), eventId, userId, seatIds, clock.instant().plus(ttl));
    }

    public boolean isExpiredAt(Instant now) {
        return !now.isBefore(expiresAt);   // expired AT expiresAt, not one tick after
    }
}
```

The reassignment `seatIds = List.copyOf(seatIds)` is the **defensive copy**. Without it, a caller could keep the original `ArrayList` and change the hold's seats after it was created.

### 4. Booking: an entity, so equality is by id (10 min)

An **entity** is an object with an identity that survives changes: booking `B-42` is still `B-42` after its status moves from `CONFIRMED` to `CANCELLED`. So `Booking` is a final class whose `equals`/`hashCode` use **only the id**. If you made it a record, two snapshots of the same booking with different statuses would be "different", and a `Set<Booking>` would hold both.

The status rules live on the enum. That puts the whole state machine in one readable place:

```java
package com.tickethub.booking;

import java.util.Set;

public enum BookingStatus {
    HELD, CONFIRMED, EXPIRED, CANCELLED;

    public boolean canTransitionTo(BookingStatus next) {
        return switch (this) {
            case HELD -> Set.of(CONFIRMED, EXPIRED, CANCELLED).contains(next);
            case CONFIRMED -> next == CANCELLED;
            case EXPIRED, CANCELLED -> false;
        };
    }
}
```

```java
package com.tickethub.booking;

import java.time.Clock;
import java.time.Instant;
import java.util.List;
import java.util.Objects;
import java.util.UUID;

public final class Booking {
    private final UUID id;
    private final long eventId;
    private final String userId;
    private final List<Long> seatIds;
    private final BookingStatus status;
    private final long totalCents;
    private final Instant createdAt;

    public Booking(UUID id, long eventId, String userId, List<Long> seatIds,
                   BookingStatus status, long totalCents, Instant createdAt) {
        if (totalCents < 0) throw new IllegalArgumentException("totalCents must be >= 0");
        if (seatIds == null || seatIds.isEmpty()) throw new IllegalArgumentException("at least one seat");
        this.id = Objects.requireNonNull(id);
        this.eventId = eventId;
        this.userId = Objects.requireNonNull(userId);
        this.seatIds = List.copyOf(seatIds);
        this.status = Objects.requireNonNull(status);
        this.totalCents = totalCents;
        this.createdAt = Objects.requireNonNull(createdAt);
    }

    public static Booking confirmedFrom(SeatHold hold, long centsPerSeat, Clock clock) {
        long total = Math.multiplyExact(centsPerSeat, hold.seatIds().size());   // overflow throws, never wraps
        return new Booking(UUID.randomUUID(), hold.eventId(), hold.userId(), hold.seatIds(),
                BookingStatus.CONFIRMED, total, clock.instant());
    }

    public Booking transitionTo(BookingStatus next) {
        if (!status.canTransitionTo(next)) throw new IllegalStateException(status + " -> " + next + " is not allowed");
        return new Booking(id, eventId, userId, seatIds, next, totalCents, createdAt);
    }

    @Override public boolean equals(Object o) { return o instanceof Booking b && id.equals(b.id); }
    @Override public int hashCode() { return id.hashCode(); }

    public UUID id() { return id; }
    public long eventId() { return eventId; }
    public String userId() { return userId; }
    public List<Long> seatIds() { return seatIds; }
    public BookingStatus status() { return status; }
    public long totalCents() { return totalCents; }
    public Instant createdAt() { return createdAt; }
}
```

In CAPSTONE-1 to CAPSTONE-4 a booking is only created at confirm time, so it starts `CONFIRMED`. The other statuses come into play once bookings are persisted and expire (CAPSTONE-5 and CAPSTONE-7).

### 5. The exception hierarchy (8 min)

The API will need one stable string per failure that clients and alerts can key on. Messages change; codes do not. The exceptions are **unchecked** because callers cannot recover from them locally. They travel up to one handler that maps them to HTTP (CAPSTONE-4), which is the design rule from JAVA-FUND-4.

```java
package com.tickethub.common;

public abstract class TicketHubException extends RuntimeException {
    private final String code;

    protected TicketHubException(String code, String message) {
        super(message);
        this.code = code;
    }

    public final String code() { return code; }
}
```

```java
package com.tickethub.booking;

import com.tickethub.common.TicketHubException;
import java.util.List;

public class SeatUnavailableException extends TicketHubException {
    public SeatUnavailableException(long eventId, List<Long> seatIds) {
        super("SEAT_UNAVAILABLE", "Seats " + seatIds + " are not available for event " + eventId);
    }
}
```

### 6. Tests (12 min)

```java
class SeatHoldTest {
    private final Clock clock = Clock.fixed(Instant.parse("2026-11-01T10:00:00Z"), ZoneOffset.UTC);

    @Test
    void expiresExactlyAtExpiresAt() {
        SeatHold hold = SeatHold.create(1, "u1", List.of(1001L), clock, Duration.ofMinutes(10));

        assertThat(hold.isExpiredAt(Instant.parse("2026-11-01T10:09:59Z"))).isFalse();
        assertThat(hold.isExpiredAt(Instant.parse("2026-11-01T10:10:00Z"))).isTrue();
    }

    @Test
    void copiesSeatIdsDefensively() {
        List<Long> seats = new ArrayList<>(List.of(1001L));
        SeatHold hold = SeatHold.create(1, "u1", seats, clock, Duration.ofMinutes(10));
        seats.add(1002L);

        assertThat(hold.seatIds()).containsExactly(1001L);
    }

    @Test
    void rejectsDuplicateSeats() {
        assertThatThrownBy(() -> SeatHold.create(1, "u1", List.of(1001L, 1001L), clock, Duration.ofMinutes(10)))
                .isInstanceOf(IllegalArgumentException.class)
                .hasMessageContaining("duplicate");
    }
}
```

## Hints

- **A record compact constructor cannot `return` early.** Just throw. Assigning to a parameter (`seatIds = List.copyOf(seatIds)`) is how you normalise a field.
- **`List.copyOf` throws `NullPointerException` on null elements.** That is a feature here, but your test should then expect NPE, not IAE.
- **`Clock.fixed` needs a zone.** Use `ZoneOffset.UTC` and never rely on the machine's default zone.
- **Do not put HTTP status codes on the exceptions.** The domain must not know about HTTP; the mapping lives in the web layer (CAPSTONE-4).
- **`Math.multiplyExact` matters.** `long` overflow wraps silently to a negative total; `multiplyExact` throws instead.

## Talk about it in interviews

**"When do you use a record, and when a class?"**
- *What:* a record is a transparent, immutable carrier whose equality is all its fields.
- *How it works inside:* the compiler generates a canonical constructor, accessors, and `equals`/`hashCode`/`toString` over every component. The fields are `final`, but the objects they point to can still be mutable, which is why you defensively copy lists.
- *Where used:* in TicketHub, `Seat`, `Venue`, `Event` and `SeatHold` are values, so they are records. `Booking` is an entity whose status changes, so it is a class with id-based equality.
- *What goes wrong:* a record that holds a mutable `List` without a copy is not really immutable. A record used as a JPA entity breaks, because JPA needs a no-arg constructor and mutable state (that comes up in CAPSTONE-5).

**"Why `long` cents instead of `double`?"** First the what: binary floating point cannot represent 0.10 exactly. Inside, `0.1 + 0.2 != 0.3`, and the rounding errors pile up across sums. In TicketHub, `totalCents` is a `long` and multiplication uses `multiplyExact`. What goes wrong otherwise: off-by-a-cent totals, and reconciliation failures with the payment provider. `BigDecimal` is the alternative when you need fractions of a cent or currency conversion.

**"How do you test time-dependent code?"** Inject a `Clock` instead of calling `Instant.now()`. The `Clock` is just another dependency, and in tests it is `Clock.fixed` or a mutable test clock. In TicketHub, hold expiry is tested at the exact boundary without sleeping. What goes wrong otherwise: flaky tests that pass or fail depending on the machine's speed or time zone.

**"How do you design exceptions for a service?"** Use one unchecked base type with a stable machine-readable `code()`, and a specific subclass per failure. Callers catch the specific type, and one handler maps codes to HTTP. What goes wrong: checked exceptions leaking through every layer, or a generic `RuntimeException("error")` that alerting cannot tell apart from a bug.
